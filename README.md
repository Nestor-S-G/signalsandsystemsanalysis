# 📉 Signals and Systems Analysis

**Computational coursework completed in MATLAB/Octave for a Master's program focusing on the mathematical analysis and processing of signals and dynamic systems.**
---

### 🔬 Core Topics Covered

The project is structured around key concepts in Signals and Systems Theory:

| Topic Area | Focus | Key Files |
| :--- | :--- | :--- |
| **System Modeling** | Exercises covering the representation and behavior of **Continuous-Time and Discrete-Time Systems**. | `Tema1.m`, `Tema2.m` |
| **Transform Analysis** | Practical application of transforms (e.g., **Fourier or Laplace**) for system analysis in the frequency domain. | `Tema3.m`, `Tema4.m` |
| **Signal Processing** | Analysis and manipulation of signals, potentially including concepts like **Convolution, Sampling, or Filtering**. | `Tema5.m`, `Tema6.m` |
